# Rejestr ryzyk

| Ryzyko | Skutek | Działanie |
|---|---|---|
| Niewłaściwy program finansowania | Odrzucenie wniosku | Weryfikacja operatora i regulaminu |
| Brak dokumentów źródłowych | Niekompletny wniosek | Inwentaryzacja PDF |
| Niepotwierdzona kwalifikowalność wydatków | Korekta budżetu | Sprawdzenie katalogu kosztów |
| Nieweryfikowalne parametry sprzętu | Błędny zakup | Oferty i kryteria odbioru |
| Dane osobowe w repozytorium | Naruszenie prywatności | Nie publikować danych wrażliwych |
